BookPilot Rooms

A booking and room-management app for small Philippine accommodations — record Messenger-confirmed stays, keep a room calendar, track deposits and balances, and copy confirmations back to guests. Built for the web with React, Cloudflare Workers, and D1.

Open live demo Demo video

Problem

Small guesthouses and room-for-rent businesses in the Philippines often confirm bookings through Facebook and Messenger, then track availability, payments, and check-ins in notebooks, spreadsheets, or chat threads. That makes it hard to see which rooms are free, what balances are still owed, and who is arriving or leaving today — especially when the owner is juggling front-desk work on a laptop or phone.

Solution

BookPilot Rooms is the business record after a guest confirms in Messenger. Owners record stays on a room calendar, move bookings through hold → confirmed → checked-in → checked-out, track deposits and balances in a payment ledger (cash, GCash, Maya, bank transfer), and copy a clean confirmation message back to chat. A daily dashboard answers “what happened today?” with check-ins, check-outs, occupancy, open balances, and payment breakdowns. Multi-room bookings, room blocks, guest history, CSV exports, and staff invites round out the pilot — desktop-first, with a usable stacked layout on phone.

Architecture

BookPilot Rooms is a monorepo with a React + Vite web app, a Hono API on Cloudflare Workers, and pure TypeScript domain rules in packages/domain. The browser never talks to D1 directly — it calls a versioned JSON API at /api/v1 with session cookies, and every query is scoped by property membership.

Drizzle ORM manages the D1 schema and migrations; money is stored as integer centavos; dates render in Asia/Manila. Conflict checks, lifecycle rules, and balance math live in domain services with Vitest coverage. OpenAPI docs stay in sync with registered routes. Cloudflare Pages hosts the web shell with a service binding to the API Worker; local dev mirrors production with Wrangler D1 local mode and SQLite.
